# ER-модель: інтернет-магазин гітар

## Домен
Зручний інтернет-магазин гітар. Клієнти роблять замовлення, у замовленні
може бути кілька гітар, а кожна гітара належить певному бренду.

## Чому цей домен
Гітари бувають різними: різні моделі, бренди, ціни, кількість на складі.
Тому домен підходить для цієї лабораторної: є кілька сутностей зі
зв'язками різних типів, зокрема «багато-до-багатьох» зі власними
атрибутами

- `ER-diagram.md`: ER-діаграма в Mermaid (`erDiagram`)
